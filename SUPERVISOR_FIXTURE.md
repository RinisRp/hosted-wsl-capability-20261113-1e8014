# Harmless cross-step supervisor fixture

The explicit `supervisor_fixture=true` dispatch input selects only a synthetic
test on the reviewed feature branch. Source/runtime qualification and parent
diagnostics are excluded. No private packet, JIT registration, real runner,
database, private repository source, owner credential or public ACK ref is used.

Separate Start, official artifact upload, Sign and Wait steps test a detached
hidden PowerShell owner's exact PID, creation time, image and script hash. A
harmless worker naturally exits either0 or7. Signing requires the corresponding
known terminal result; exit7 remains unsuccessful worker execution. The synthetic
RSA3072 CNG key is nonexportable. Only public parameters leave CNG. The owner
verifies the production terminal-ACK signature and waits until another step holds
its exact generation before exiting naturally. Final success also requires the
synthetic key to be absent.

Launch intent is consumed before process creation. Unknown outcomes cannot be
replayed. Partial-generation records support reconciliation. Closed, flushed
temporary files are renamed without overwrite so readers cannot observe partial
markers or ACKs. Key cleanup uses a separate owned creation receipt and public-key
fingerprint before context-dependent process reconciliation. Existing collision
keys are never deleted.

Pure controls cover cryptographic refusal, typed record/generation mismatches,
launch replay/failure handling and actual filesystem publication. Only a fresh
hosted run can prove cross-step lifetime. Artifact uploads use an exact file
allowlist and contain only bounded synthetic public records and empty worker I/O.

This fixture cannot qualify a real private session, HTTP ACK transport, private
job success, canonical database execution, memory erasure, descendant containment
or long-duration endurance. The named private owner is not implemented or wired.
Existing source/runtime qualification results remain bound to their own commits.

Startup diagnostics advertise the exclusive public evidence root before launch.
The owner validates that ordinary nonce-derived root before importing dependencies
and records only fixed bootstrap stages and failure categories. These records
remain diagnostic and do not grant readiness. The ready deadline is90 seconds; the240-second failure hold remains fixed.

a late ACK or expired aggregate lease still fails.
